# プライバシーポリシー

本ポリシーは [ニチアサセイヴァー配信 予約ツール](vs-stream-scheduler) に適用されます。

## 1. 取得する情報

本ツールは、Google アカウントの認可を通じて YouTube Data API v3 へアクセスします。取得するのは、認可した本人の YouTube チャンネルにおけるライブ配信枠、配信ストリーム、および本ツールが作成した配信の動画情報（タイトル、説明文、カテゴリ、タグ、配信の開始時刻）のみです。視聴履歴、視聴者の情報、個人プロフィールは取得しません。

## 2. 利用目的

取得した権限は、認可した本人のチャンネルについて、次の目的にのみ使用します。それ以外の目的には使用しません。

- ライブ配信の予約枠を作成し、既存の配信ストリームと結びつける
- 予約枠にタイトル・説明文・カテゴリ・タグ・サムネイル画像を設定する
- 配信の終了後、配信の開始時刻を読み取り、説明文に試合ごとのチャプターを書き足す

## 3. 保存場所

認可情報（アクセストークンおよびリフレッシュトークン）は、本ツールを実行する利用者本人の端末内にのみ保存されます。外部のサーバーへ送信・保管することはありません。

## 4. 第三者への提供

取得した情報を第三者へ提供、販売、共有することはありません。

## 5. 権限の取り消し

利用者はいつでも Google アカウントの「サードパーティ アプリとの連携」から本ツールへの権限を取り消すことができます。取り消した時点で、本ツールは一切のアクセスができなくなります。
