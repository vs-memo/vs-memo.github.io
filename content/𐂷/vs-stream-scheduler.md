# ニチアサセイヴァー配信 予約ツール

個人が自分の YouTube チャンネルで毎週おこなうライブ配信について、予約枠の作成と配信後の説明文の更新を自動でおこなうための個人用ツールです。一般に配布・提供しているサービスではなく、作者本人のチャンネル運用にのみ使用しています。

## できること

- 作者自身の YouTube チャンネルに、次回配信ぶんのライブ予約枠を1つ作成する
- 作成した予約枠に、既存の配信ストリームを結びつける
- 作成した予約枠に、タイトル・説明文・カテゴリ・タグ・サムネイル画像を設定する
- 配信の終了後、その配信の開始時刻を読み取り、説明文に試合ごとのチャプター（時刻と対戦カード）を書き足す

## 使用する権限

YouTube Data API v3（スコープ `https://www.googleapis.com/auth/youtube`）

- ライブ配信枠の参照・作成と、配信ストリームへの結びつけ
- 配信ストリームの参照
- 作者自身の動画の情報（タイトル、説明文、カテゴリ、タグ、配信の開始時刻）の参照と更新
- サムネイル画像の設定

取得した権限は上記の目的にのみ使用します。詳細は [プライバシーポリシー](vs-stream-scheduler-privacy) を参照してください。
