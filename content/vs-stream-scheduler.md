# ニチアサセイヴァー配信 予約ツール

個人が自分の YouTube チャンネルで毎週おこなうライブ配信について、その予約枠を自動で作成するための個人用ツールです。一般に配布・提供しているサービスではなく、作者本人のチャンネル運用にのみ使用しています。

## できること

- 作者自身の YouTube チャンネルに、次回配信ぶんのライブ予約枠を1つ作成する
- 作成した予約枠に、既存の配信ストリームを結びつける

## 使用する権限

YouTube Data API v3（ライブ配信枠の作成および配信ストリームの参照）

取得した権限は上記の目的にのみ使用します。詳細は [プライバシーポリシー](vs-stream-scheduler-privacy) を参照してください。
